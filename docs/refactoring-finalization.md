# 추가 리팩토링 정리 — 2026-10-12

공식 저장소 업로드를 보류하고 남은 구조 개선 세 단위를 적용했다.
버전은 1.2.1 후보로 유지하며 기능 추가·인증 정책·저장 스키마 변경은 포함하지 않는다.

## 책임 경계

- `route_controller.py`: 요청 검증, 입력 핀 정리, 키 요청 후 프로젝트 세대 확인,
  경로 결과 payload/이력 저장 조정과 완료·실패 안내. 필요한 콜백만 전달받는다.
- `viewer_adapter.py`: 도크/외부 브라우저의 중심·해상도·안내·이력·입력 복원·상태·초기화 전달.
  기존 Qt/HTTP 시그널명과 JSON 계약, 도크 반향 차단과 외부 클라이언트 출처를 유지한다.
- `web/viewer_sync.js`: 지도 드래그·휠·줌, 로드뷰 위치·시선 전달, 프로그램 이동 반향 억제,
  비동기 촬영 지점 조회와 타이머 상태. SDK 객체와 브리지는 getter로 전달받는다.

플러그인은 QAction·객체 조립·클라이언트/프로젝트 수명·이전 요청 판별과 QGIS 표시 콜백을
유지한다. HTML은 SDK 생성·레이아웃·DOM 이벤트 조립을 유지한다. 이 조립 책임까지
별도 파일로 옮기는 것을 배포 전 필수 작업으로 삼지는 않는다.

## 유지한 동작과 추가 보강

입력 좌표, 표시용 결과 핀, 경로/안내 속성, 이력 파일 형식, 줌 해상도 계산,
카카오 단계 1~14, QGIS 축척 잠금과 줌 중 로드뷰 위치 유지 정책을 변경하지 않는다.
이력 저장 실패 시 생성한 경로는 유지하되 실패 안내를 보내고 활성 이력 ID를 비운다.

프로젝트 초기화 시 지도·로드뷰·줌 타이머를 함께 취소하고 대기 중 촬영 지점 조회를
무효화한다. 초기화 이후 새로운 이동·조회는 정상 재개한다.

## 검증

- Python 75개: 기존 69개 및 공통 전달 어댑터 신규 6개.
- JavaScript 48개: 기존 45개 및 초기화/로드뷰 이동 신규 3개.
- 뷰어 조립의 6개 inline 스크립트 및 외부 브리지 구문 검사, Python 컴파일.
- Bandit: 발견 항목·제외 파일·비활성 규칙 0건.
- QGIS 3.44.14/4.2.2: 경로 컨트롤러 콜백 7항목, 경로 핀, 줌, 브리지 전달,
  프로젝트 clear/read, 런타임 HTML 조립, 이력 가져오기/삭제/실패 복구,
  네 형식 내보내기와 표시 레이어 수명 회귀 검사.

검사는 fixture와 테스트 전용 파일을 사용하며 실제 키·SDK 네트워크를 사용하지 않는다.
QGIS 3은 외부 브라우저, QGIS 4는 WebEngine 런타임으로 검사했다.
