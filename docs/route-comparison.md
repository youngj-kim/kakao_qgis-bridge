# GPKG 경로 비교

플러그인 메뉴의 `GPKG 경로 비교...`를 연다. A/B에서 GPKG 파일을 열고 각 파일의 경로를 선택한다. 같은 파일의 서로 다른 경로도 선택할 수 있다.

- 표: 출처, 조회 시점, 출발·도착 이름, 거리와 소요 시간.
- 조건 안내: 출발·도착 좌표 사이의 거리, 20m 초과 여부, 경유지 JSON 차이 또는 확인 불가, 동일 경로 선택 여부.
- 차이: B − A 거리(m)와 시간(분).
- 지도 표시: A는 파랑 실선, B는 주황 점선. 선택을 바꾸면 이전 비교 표시를 지운다. `비교 표시 지우기`로도 제거할 수 있다.

현재 지원 입력은 EPSG:4326 GPKG의 `kakao_route_history` 또는 `naver_route_history` 레이어다. 출발·도착 좌표 필드와 선 geometry가 필요하다. 거리·시간이 없으면 정보 없음으로 표시한다. 실제 카카오·네이버 API를 호출하지 않으며 원본 파일을 읽고 별도의 메모리 표시 레이어를 만든다. 카카오 세션 이력에 가져오기/추가하지 않는다.

출발·도착 좌표가 20m 이내라는 안내는 위치 비교 기준이다. 회피 옵션·차량 옵션·교통 상황까지 같은 조건이라는 뜻은 아니다. 경유지 비교는 저장된 JSON 전체를 비교한다. 소요 시간은 각 서비스의 조회 당시 예측값이며 현재 교통이나 실제 주행 시간을 보장하지 않는다.

프로젝트 전환은 비교 표시 참조를 비운다. 선택한 파일/경로는 비교 창에 유지되어 명시적으로 다시 표시할 수 있다. 창은 반복해서 열어도 같은 인스턴스를 사용하고 plugin unload에서 신호와 비교 표시를 정리한다.

## 검증 — 2026-10-08

`tests/qgis_route_comparison_smoke.py`는 기본 실행 시 임시 네이버 형식 GPKG를 생성하고 그 복사본에 카카오 테이블을 구성한다. 사용자 파일이나 네트워크 호출이 필요 없다. 선택적으로 첫 인수에 네이버 형식 GPKG를 전달하고 두 번째 인수에 화면 캡처 출력 경로를 전달할 수 있다.

Windows QGIS 3.44.14/4.2.2의 offscreen 런타임에서 두 공급자 읽기, 좌표 차이/거리·시간 안내, 선택 변경, 두 경로 표시·반복 표시·제거, 프로젝트 clear 이후 표시, 메뉴 열기와 unload 정리, 원본 SHA-256 보존을 확인했다. 합성 fixture 검사이며 외부 공급자의 모든 스키마 변형을 지원한다는 의미는 아니다.
