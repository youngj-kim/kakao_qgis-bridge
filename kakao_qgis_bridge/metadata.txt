about=Shows Kakao Maps JavaScript API content inside a QGIS dock widget and synchronizes center positions between QGIS, Kakao Map and Roadview. Includes Local search, Roadview direction display, Kakao Mobility route search, guidance and history import/export. Requires user-provided JavaScript and REST API keys. Register http://localhost:8081 and http://localhost:8082 as JavaScript SDK domains for external bridge fallback and simultaneous sessions. See the packaged README.md for setup and limits. Kakao tile URLs are not used as XYZ/TMS layers.
